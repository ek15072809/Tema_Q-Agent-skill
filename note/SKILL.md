# Note.com Article Skill

## 概要
ユーザーが書きたいテーマを入力 → Agentがnote.comで人気記事を検索 → パターンを抽出 → それを参考に執筆。
note.comの**独自仕様**（限定マークダウン・画像ドラッグ&ドロップ・タイトル文字数）を厳守。

## 同梱ヘルパースクリプト
**`skill/note/scripts/note_skill.py`** を使用:

- `NoteArticle` データクラス — タイトル・リード・本文・カバー案・ハッシュタグ
- `PopularNote` データクラス — 検索で見つけた人気記事のメタ情報
- `analyze_popular_notes(notes)` — 複数の人気記事から共通パターンを抽出
- `render_article_md(article)` — 完成記事Markdown生成
- `cover_image_brief(theme, tone, palette)` — 1280×670カバー画像のブリーフ生成
- `check_note_compliance(md)` — 非対応マークダウン検出（`#`/`####+`/`![]()`/テーブル等）

```python
import sys; sys.path.insert(0, "skill/note/scripts")
from note_skill import (NoteArticle, PopularNote, analyze_popular_notes,
                        render_article_md, cover_image_brief, check_note_compliance)
```
`python skill/note/scripts/note_skill.py` でデモ動作を確認できます。

## 実行フロー（5フェーズ・必ず順序通りに）

### フェーズ1: 要件ヒアリング
ユーザー入力から以下を抽出:

- **テーマ**: 何について書きたいか（例: 「ChatGPTの活用法」「副業始め方」）
- **想定読者**: 初心者 / 中級者 / 上級者
- **目的**: 集客 / 収益化 / 知見共有 / ブランディング
- **文字数目安**: 1,000字 / 1,500字 / 2,000字 / それ以上
- **トーン**: 専門的 / カジュアル / 体験談 / 解説

不明な場合は `question` ツールで1〜2回だけ追加質問。

### フェーズ2: 人気記事検索（リアルタイム・必須）

`websearch` と `webfetch` を使って、テーマに関連する**実際の人気note記事**を複数取得する。

#### 検索クエリ戦略
```
websearch("site:note.com {テーマ} スキ")
websearch("site:note.com {テーマ} 人気")
websearch("site:note.com {テーマ} 読まれた")
websearch("note.com {テーマ} バズる 書き方")
websearch("{テーマ} note 稼げた 月収")
```

#### 取得後の処理
1. 上位5〜10件のURLを `webfetch` で本文取得
2. 各記事から以下を抽出（`PopularNote` データクラスで構造化）:
   - URL
   - タイトル（文字数も記録）
   - リード文（最初の50文字）
   - 見出し構造（`##` `###` のみ抽出）
   - 文字数
   - 画像枚数
   - ハッシュタグ
   - スキ数（取得可能な場合）

#### 検索が上手くいかない場合のフォールバック
```
websearch("note {テーマ} おすすめ")
websearch("{テーマ} note マガジン")
```
- 検索結果が少ない場合は同テーマのブログ・Twitter/Xのバズ投稿も参考にする
- **絶対に**: 人気記事を見ずに執筆しない（フェーズ3がスキップ不可）

### フェーズ3: パターン分析

`analyze_popular_notes(notes)` で複数記事から共通パターンを抽出:

#### 抽出する要素
1. **タイトル傾向**:
   - 平均文字数
   - よく使われる構造（数字入り / 疑問形 / 体験談 / 【】 / Before→After 等）
   - 感情誘導語の有無
   - 対象読者を明示しているか

2. **構造傾向**:
   - 平均文字数と読了時間の関係
   - 見出しの数・間隔
   - リード文の長さ
   - 画像の配置タイミング

3. **ハッシュタグ傾向**:
   - 広域タグ（`#note` `#ライティング` 等）とニッチタグの混ぜ具合
   - 平均個数

4. **結びのCTA傾向**:
   - スキ・コメント・フォロー促進の有無
   - 自己紹介・マガジン誘導の有無

#### 分析結果を執筆に反映
分析で見つけたパターンを**そのテーマの文脈に合わせて**適用。
単なるコピーではなく、ユーザーの体験・知見を軸にする。

### フェーズ4: 執筆

#### note.com 書式（厳守・独自仕様）

##### 対応マークダウン（限定）
| 要素 | 書式 | 注意 |
|---|---|---|
| 大見出し (h2) | `## ` + スペース | `#` (h1) は不可 |
| 小見出し (h3) | `### ` + スペース | `####` 以上も不可 |
| 太字 | `**text**` | **末尾に半角スペ必須** |
| 取り消し線 | `~~text~~` | 末尾半角スペ必須 |
| 引用 | `> ` + スペース | 段落単位 |
| 箇条書き | `- ` + スペース | `*` も可 |
| 番号付 | `1. ` + スペース | |
| 区切り線 | `---` | |
| コード | ` ``` ` | ツールバーの「コード」も可 |

##### 非対応（絶対避ける）
- `#` (h1), `####`〜`######`（h4-h6）
- `*text*` イタリック（非対応・太字で代用）
- `![alt](url)` 画像マークダウン（**動かない**）
- `| table |` テーブル（プレーンテキスト化する）
- `- [ ]` チェックリスト
- 中央・右寄せ（ツールバーのみ・マークダウン不可）

##### 画像挿入（重要）
noteは画像マークダウン非対応。LLMは**プレースホルダー**を出力:

```
[画像挿入: ここに〇〇の図をアップロード（推奨1280×670px、1.91:1）]
```

ユーザーがnote編集画面で `+` → 画像、またはドラッグ&ドロップで挿入。

##### カバーアイキャッチ画像（見出し画像）

| 項目 | 仕様 |
|---|---|
| サイズ | **1280×670px**（推奨 1920×1006px） |
| 比率 | **1.91:1** |
| 容量 | **10MB以内** |
| 形式 | JPG, PNG, GIF, HEIC |
| 設定場所 | タイトル上の「見出し画像」欄（本文外） |

#### 本文構成テンプレ

```
[リード文：50文字以内。X共有時の表示文になる]

## {フェーズ3で分析した見出し傾向に基づく見出し}

本文。1文50文字以内。1段落5行以内。
スマホ読者を意識して頻繁に改行。

### {小見出し}

- 箇条書きで情報密度上げる
- 具体数字・固有名詞を入れる
- 抽象説明より具体例

[画像挿入: 〇〇の図（推奨1280×670px）]

## {次の見出し}

本文...

---

## まとめ

要点3行で振り返り。

最後にスキ・フォローを促すCTA:
「スキ・コメント・フォローいただけると励みになります！」
```

#### 文字数目安

| 種類 | 文字数 | 読了時間 |
|---|---|---|
| 短い（軽い話題） | 1,000-1,500字 | 2-3分 |
| 標準 | 1,500-2,000字 | 3-4分 |
| 長尺・有料販売 | 2,000-3,500字 | 4-7分 |

※ 1見出しにつき約400字が目安

### フェーズ5: ハッシュタグ設定

#### 設定方法（2通り）
1. 公開設定画面の「ハッシュタグ」欄
2. 本文に `#タグ` 直書き（自動登録）

#### 選び方
- **3-6個**（多すぎはNG文化）
- 広域1-2 + ニッチ2-3 の混成
- フェーズ3で分析したハッシュタグ傾向を参考に選定

## 最終チェック（公開前）

`check_note_compliance(md)` で自動検証 + 以下目視:

- [ ] タイトル25字以内（分析した平均文字数を参考）
- [ ] カバー画像1280×670px用意
- [ ] リード文50字以内でフック
- [ ] `##` `###` 見出しのみ（`#` `####` 使ってない）
- [ ] 太字は `**text** ` (末尾スペース)
- [ ] 画像は `[画像挿入: ...]` プレースホルダー
- [ ] テーブル使ってない（リストで代用）
- [ ] 1文≤50字・1段落≤5行
- [ ] ハッシュタグ3-6個
- [ ] 結びにCTA（スキ・コメント・フォロー）
- [ ] 音読して違和感ない

## よくある失敗

| 失敗 | 対策 |
|---|---|
| 検索せず執筆 | フェーズ2はスキップ不可・必ずwebsearch実行 |
| 画像マークダウン書いた | `![](url)` 不可・プレースホルダー使用 |
| `#` 見出し使った | `##` `###` のみ対応 |
| 太字反映されない | 末尾半角スペース必須 |
| テーブル書いた | 非対応・リストか文章で代用 |
| 人気記事の丸写し | パターンは参考・内容は独自 |
| ハッシュタグ多すぎ | 3-6個に絞る |
| リード文ない | 必須・50字以内で書く |
